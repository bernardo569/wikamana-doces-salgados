# Wikamana — Doces & Salgados

Site institucional e catálogo de preços da Wikamana, pastelaria artesanal em Camama Chimbicato, Luanda.

## Desenvolvimento local

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm check
pnpm build
```

O site está preparado para publicação no GitHub Pages através do workflow em `.github/workflows/deploy-pages.yml`. Cada push para `main` inicia automaticamente uma nova publicação.
